# parothegreat-portfolio

Personal website for Moehammad Alvaro Pirata Prayogo, also known as
`parothegreat`.

The site keeps the layout, structure, and general concept of Ryan Aulia's
`aulianza.id` template, then replaces the public identity and content with
Alvaro's own profile: SysAdmin, DevOps engineer, penetration testing
enthusiast, and Industrial Electronics Engineering student from Bekasi,
Indonesia.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma
- SWR
- Framer Motion
- Jest

## Getting Started

Install dependencies:

```bash
yarn install
```

Copy `.env.example` to `.env`, then fill in the values for the integrations you
want to enable.

Run the development server:

```bash
yarn dev
```

Open http://localhost:3000 in your browser.

Production server automation requirements are documented in
[`SERVER_DEPLOYMENT.md`](SERVER_DEPLOYMENT.md).
